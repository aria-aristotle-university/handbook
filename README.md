## Adding a guide

Each guide lives in its own folder with an `index.html`, e.g. `cad/index.html` → `…/handbook/cad/`. Add it to the table above and to the root `index.html`.

This repository is **public**. Never put personal data, member lists, recruitment material, passwords or keys here.
